# 🌲 BugaichyBot (Vanilla Edition)

Швидкий, стабільний та ванільний Telegram-бот для чатів з інтерактивною системою взаємодії, стосунками, погодою та професійним завантажувачем медіа з соцмереж.

## 🚀 Основні можливості

### 1. 🎬 Multi-Engine Video Saver
- **Миттєве завантаження:** надсилання посилань у чат автоматично завантажує відео у високій якості.
- **Підтримувані платформи:** TikTok (без водяного знака), Instagram (Reels/Posts), YouTube Shorts, Twitter/X.
- **Багаторівнева система завантаження:** Direct API (TikWM, fxtwitter) ➔ Оптимізований `yt-dlp` ➔ Резервні Cobalt API.
- **Чистий UX:** жодних зайвих коментарів, автоматичне видалення тимчасових статусів завантаження.

### 2. 🎭 Ванільне РП та Вільні Дії
- Підтримка будь-яких дієслів через префікси `!` або `/` (через reply або `@username`):
  - Приклади: `!обняв @user`, `!поцілував`, `!вдарив лопатою`, `!пригостив кавою`.
- Генерація клікабельних HTML-посилань на профілі (`tg://user?id=`).

### 3. ❤️ Система Стосунків та Шлюбів
- `/dating` (`!пропозиція [@user]`) — пропозиція зустрічатися з інлайн-кнопками підтвердження.
- `/relationships` (`!стосунки`) — список усіх пар чату та їхніх рівнів кохання.
- `/myrelationships` — картка власних стосунків.
- `/breakup` (`!розрив`) — розірвання стосунків.
- Парні дії прокачування очок кохання: `/kiss`, `/hug`, `/love`, `/date`, `/gift`.

### 4. 👤 Статичні Профілі та Аналітика
- `/profile` (`!профіль [@user]`) — інтерактивна картка з вкладками (Огляд, Роль & Стиль, Психоаналіз, Справжні теми, Сленг, Статистика).
- `/id` (`!інфо [@user]`) — Telegram ID, роль та пара у чаті.
- `/chatstats` (`!стата`) — щоденний топ активності учасників чату.

### 5. 🎲 Розваги та Погода
- `/risk` (`!ризик`) — швидка РП-рулетка з 50 лор-подій.
- `/flipcoin` — кинути монетку (Орел чи Решка).
- `/weather` (`!погода [місто]`) — прогноз погоди через Open-Meteo та wttr.in.

## 🛠 Встановлення та запуск

1. **Клонування та перехід у папку:**
   ```bash
   git clone <repo_url>
   cd bugaichybot
   ```

2. **Створення та активація віртуального середовища:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. **Створення файлу `.env`:**
   ```env
   BOT_TOKEN=ваш_токен_від_BotFather
   DEFAULT_CHAT_ID=-1004397346715
   ```

4. **Запуск бота:**
   ```bash
   python main.py
   ```
